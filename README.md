# fancam-helper

콘서트 직캠 유튜브 제목, 설명, 해시태그 생성 도우미입니다.

- 가수명 기반 팬클럽명 AI 추천과 한국어/영어/한+영 표기 선택을 지원합니다.
- 과거 공연 셋리스트와 대표곡을 웹 검색해 예상곡을 추천하고, 원하는 곡만 작업 목록에 추가할 수 있습니다.
- 유튜브에서 사용할 수 없는 꺾쇠 특수기호는 생성 결과와 복사할 설명에서 자동 제거합니다.
- 유튜브 제목에는 대표 투어·공연명을 유지하면서 100자 이내로 자동 조정하고, 해시태그에는 현재 공식 멤버만 사용합니다.
- 콘서트명에 지역이 있으면 `IN INCHEON`, `IN SEOUL`, `IN GOYANG`처럼 대표 공연명과 함께 제목에 유지합니다.
- 설명 전체에는 `#` 해시태그를 유지하고, 별도 해시태그 목록은 `#` 없이 쉼표로 구분합니다.
